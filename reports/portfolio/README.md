# Local Olist projections — not distributed

The six Olist-derived JSON files previously prepared in this directory are now
excluded from the publication candidate. Their suitability for the intended
employment portfolio remains unresolved under the dataset's noncommercial terms.
Local copies remain unchanged and ignored by Git; this directory ships only this
notice. [NOTICE.md](../../NOTICE.md) preserves Olist attribution, license links
and transformation descriptions. See the [individual asset review](../../docs/DATASET_LICENSE.md).

The application, exporter and Olist views remain available for locally generated
reports. The exporter does not grant redistribution rights. Raw datasets and
private source reports remain excluded. Use the [synthetic CSV demo](../../docs/DEMO.md)
for a credential-free public demonstration; tests also generate synthetic
projections without borrowing historical Olist counts or live-model usage.
